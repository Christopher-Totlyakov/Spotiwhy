# 🎵 Spotiwhy

Допълната документация е в pdf файла Курсова работа Python.

**Spotiwhy** е музикално десктоп приложение, разработено с Python и `tkinter`, което позволява на потребителя да преглежда, филтрира, редактира и **възпроизвежда песни директно чрез YouTube**.  

## 🚀 Функционалности

- Преглед на песни по заглавие, жанр, изпълнител и рейтинг
- Добавяне и редактиране на песни
- Възможност за зареждане на песни от JSON файл
- **Контекстно меню с десен бутон** върху песни с опции:  
  `Пусни`, `Редактирай`, `Изтрий`
- Възпроизвеждане на песни чрез YouTube и `yt-dlp`
- Среден рейтинг на всички песни в реално време

## 📦 Инсталация и стартиране

> **Препоръчително:** Създайте виртуална среда, за да избегнете конфликти с глобални библиотеки.

### 1. Клонирайте проекта

```bash
git clone https://github.com/Christopher-Totlyakov/Spotiwhy
cd Spotiwhy
```

### 2. Създайте виртуална среда (препоръчително за да не се работи с глобални)
```bash
python -m venv venv
```

### 3. Активирайте виртуалната среда
```bash
venv\Scripts\activate

#for macOS / Linux:
source venv/bin/activate
```
### 4. Инсталирайте зависимостите

```bash
pip install -r requirements.txt
```
### 5. Стартирайте приложението
```bash
python main.py
```
## 🛠️ Зависимости
- tkinter
- pygame
- yt-dlp
- ffmpeg (наличен в системата)

## ⚠️ Важно
За правилното възпроизвеждане на песни, трябва да имате инсталиран FFmpeg на операционната си система.
